# Calendar AI Assistant — Example Commands

Type any of these into the sidebar chat (or CLI chat) to get started.
The AI infers dates relative to today, picks sensible defaults for optional fields,
and immediately writes the result to your calendar or todo list.

---

## Calendar Events

**Simple event**
```
create an event for no school tomorrow and make it a whole day event
```

**Event with location and reminder**
```
add a dentist appointment next Monday at 2pm at City Dental Clinic, remind me 30 minutes before
```

**Event with a description**
```
schedule a study session for Friday from 4pm to 6pm to review chapters 5 and 6 for the biology exam
```

**Recurring event**
```
set up a weekly team standup every Monday at 9am
```

**Multi-day event**
```
block out the whole weekend of June 20th and 21st for the hackathon
```

**Event with location and recurrence**
```
add a monthly book club meeting on the last Friday of each month at 7pm at the public library
```

---

## Todo Items

**Simple todo**
```
create a todo list due in four days for me to complete a research paper about CRISPR-Cas9
```

**High priority with due date**
```
add an urgent todo to submit the college application by this Friday, mark it high priority
```

**Todo with notes**
```
remind me to review the quarterly report by end of week, add a note that I need to check the revenue figures in section 3
```

**Todo with tags**
```
add a todo to buy groceries this weekend, tag it shopping and errands, low priority
```

**In-progress task**
```
add a todo for the science fair project that is already in progress, due in two weeks
```

**Multiple details at once**
```
create a high priority todo to fix the login bug before the demo on Thursday, add notes that the issue is in the auth middleware, tag it backend
```

## Asking Questions

The AI will answer from your stored data and general knowledge.

```
what events do I have coming up this week?
```

```
do I have any high priority todos due today?
```

```
am I free on Saturday afternoon?
```

```
what should I focus on today based on my todo list?
```

```
summarize what I have planned for the next three days
```

---

## Tips

- **Relative dates** work naturally — "tomorrow", "next Monday", "in four days", "this Friday"
- **Priority** is inferred from words like "urgent", "important", "whenever I get to it"
- **Reminders** are set when you say "remind me X minutes/hours before"
- **Recurrence** is picked up from "every Monday", "weekly", "monthly"
- After the AI adds something, click over to the **Calendar** or **Todo List** tab to see it — click any item to view full details or edit it
